CodeArena 2025 – Frontend Project

A small responsive frontend project developed as part of my CodeArena web development training in 2025.

The project was completed within one week using HTML, CSS, JavaScript, and Tailwind CSS. It was designed as a practical exercise to evaluate how quickly we could learn and apply a new technology that we had not previously worked with.

Technologies

  HTML5,
  CSS3,
  JavaScript,
  Tailwind CSS,
  Responsive Web Design
